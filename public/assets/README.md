# 游戏美术素材

| 文件夹 | 放什么 |
|---|---|
| `backgrounds/` | 整页或场景背景（不透明，1920×1080，WebP/JPG） |
| `characters/` | 冒险家、向导阿算、老师、头像（透明背景 PNG/WebP） |
| `maps/` | 冒险地图底图（2480×1520）与六座岛屿（透明背景） |
| `ui/` | 空白按钮、面板、木牌、彩带、宝箱、门、钥匙、星星、徽章（透明背景） |
| `enemies/` | 混乱魔王的各种状态（透明背景） |
| `effects/` | 闪光、命中、星星爆发等特效（透明背景） |
| `audio/` | 背景音乐与音效（MP3） |

文件名必须和 `public/js/assets/manifest.js` 里的一样。完整列表、尺寸和画图提示请看 `docs/美术素材指南.md`；上传后到“教师管理中心 → 美术素材”检查。

图片里不要有文字，所有文字由程序显示。
