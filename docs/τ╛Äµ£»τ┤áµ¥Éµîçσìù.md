# 美术素材指南

本平台的画面由**独立的图片文件**组成：背景、人物、地图岛屿、按钮、宝箱、怪兽、特效、声音都可以分别更换。所有文字（标题、关卡名称、题目、分数、按钮文字）都由程序显示，所以**图片里不要有任何文字或数字**。

还没上传的素材会自动使用程序画的备用图案，游戏照常运作。图片坏掉或打不开时，也会自动改用备用图案。

---

## 一、怎样上传

1. 用 ChatGPT 等画图工具生成图片，存成下面表格里的**文件名**（全部小写英文，例如 `boy-idle.png`）。
2. 放进项目的 `public/assets/<文件夹>/`。
3. 提交到 GitHub，Render 会自动重新部署。
4. 登录 **教师管理中心 → 美术素材**，按“重新检查”。每个素材都会显示“已上传 / 使用备用图案 / 加载失败”。系统还会检查实际尺寸和长宽比例，以及需要透明背景的图片四角是否透明。
5. 也可以把图片传给我，由我放进项目并调整位置。

**文件格式**
- 背景、地图底图：WebP（推荐，文件小）或 JPG。
- 人物、怪兽、道具、按钮、特效：WebP 或 PNG，**必须是透明背景**。
- 声音：MP3（可以另外加 OGG）。
- 同一个素材放 `.webp` 和 `.png` 两个文件时，系统优先使用 `.webp`。

**换图片**：用同名文件覆盖即可，网址会自动更新，学生的浏览器不会一直显示旧图。

---

## 二、生成图片的通用提示（给 ChatGPT）

每张图片的提示词里都加上这一段，风格才会一致：

> 明亮的卡通冒险风格，适合 10 岁小学生，粗黑描边，鲜艳饱和的颜色，柔和光影。画面中不要出现任何文字、字母、数字或标志。

人物、怪兽、道具、按钮另外加上：

> 单独一个物件，完整入镜，置中，透明背景（PNG），四周留少量空白。

按钮和面板另外加上：

> 空白的游戏按钮（或面板），中间不要有文字，四个角有装饰，中间是平整的颜色，方便拉长。

**同一个角色的不同姿势**（站立、欢呼、思考、攻击），请在同一个对话里连续生成，并说明“和上一张是同一个角色、同样的服装、同样的画风”。

## 四、冒险地图的两种做法

**做法 A（最简单）：一张完整地图**
- 只上传 `maps/map-background.webp`（2480×1520），画好海洋、木桥和六座岛屿，不要文字和编号。
- 岛屿的编号牌、名称、星星和玩家位置由程序叠加。
- 如果新地图的岛屿位置和原本不同，修改 `public/js/assets/manifest.js` 里的 `MAP_LAYOUT.islands`。`x`、`y` 是岛屿中心的位置，以地图宽高的百分比表示。

**做法 B（可以单独动画、单独变灰）：海洋底图加六张岛屿**
- `maps/map-background.webp` 只画海洋和木桥。
- 六座岛屿分别上传 `maps/island-1-start.png` 到 `maps/island-6-king.png`，都要透明背景。
- 岛屿会轻轻漂浮，未解锁的岛会自动变灰，点岛屿就能选关卡。

## 五、人物与动画

- 每个人物可以上传几种姿势，例如男生冒险家有 `boy-idle`、`boy-cheer`、`boy-think`、`boy-attack`。缺少某个姿势时，系统会改用最接近的姿势，例如没有 `boy-attack` 就用 `boy-cheer`，再没有就用 `boy-idle`。
- 动画由程序加上：站立时轻微呼吸，欢呼时跳动，Boss 受伤时摇晃，岛屿漂浮，宝箱抖动。所以只要上传静态图片。
- 学生在“设置”里选择“减少动画效果”，或电脑系统设定了减少动态时，所有持续动画都会停止。

## 六、按钮与面板（九宫格拉伸）

按钮、羊皮纸面板、木牌、彩带都会以“九宫格”方式拉伸：四个角保持原样，中间部分拉长。所以：
- 四个角的装饰要画在角落，中间保持平整。
- 按钮高度会依文字自动调整，**文字由程序放上去**，图片中间留空白。
- 如果拉伸后角落变形，可以调整清单里该素材的 `slice` 数值（角落装饰占多少像素）。
