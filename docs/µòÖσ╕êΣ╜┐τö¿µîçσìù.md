# 教师使用指南

## 一、登录
首页按 **教师教学模式** 或 **教师管理中心**，输入老师的用户名和密码。学生没有教师账户，进不来这两个地方。

## 二、教师教学模式（课堂讲解）
适合互动白板、投影机或 Google Meet 分享屏幕。

1. 左边目录选择课节：例 3（交通罚单）、讨论（能先减后加吗？）、连续退位、例 4、例 5、自我学习、思考题。
2. 底部按钮：

| 按钮 | 作用 |
|---|---|
| 开始讲解 | 先给学生 20 秒思考（可以跳过），然后开始演示 |
| 显示题目 | 只显示题目与统计表，让学生读题 |
| 显示提示 | 弹出思考提示 |
| 下一步骤 / 上一步骤 | 一步一步写出课本格式的竖式（进位、退位划去、部分积、长除法） |
| 自动播放 | 自动逐步演示，再按一次暂停 |
| 揭晓答案 | 直接显示完整的竖式与答案 |
| 常见错误 | 用真实的错误算法算出“错误答案”，让学生看到错在哪里 |
| 再试一道 | 从题库换一道同类题，用同样方法演示 |
| 重新演示 | 从头开始 |
| 教学指引 | 学习目标、预期错误观念、建议教学策略 |
| 全屏 | 隐藏目录，适合投影 |

键盘快捷键：→ 下一步骤，← 上一步骤，空格 自动播放 / 暂停。

3. **课堂工具**：课堂小测（全班选答案，老师按 +1 记录人数后揭晓）、倒数计时、随机抽题。

## 三、教师管理中心

### 班级与学生名单
- 新增班级，贴上名单（每行“学号 姓名”）。
- 学生第一次登录时自己设定 4 位数“冒险密码”。忘记了请按 **重设密码**。
- 学生如果输入的名字不在名单里，会以“自行登记”出现，老师可以修改或删除。
- **未提交名单** 是根据这份名单计算的，所以请尽量先输入完整名单。

### 学生学习记录
- 每一次正式评估（第六关）的得分、正确率、用时、练习时用了几次提示、提交时间。
- 全班名单的闯关进度（第 1–6 关）与提交状态。
- 按 **报告** 可以预览、写评语、下载 PDF、打印个人报告。

### 班级成绩统计 / 知识点掌握分析 / 学习困难与补救建议
- 平均分只计算已提交的学生；未提交的学生另外列出，**不当作 0 分**。
- 常见错误是根据学生**实际输入的答案**判断的（例如没有从左到右、商中间漏写 0、漏写余数）。判断不出原因时只写“计算出错”，不会乱下结论。
- 基础补救组、冲刺及格组、巩固提升组、学习困难名单都依照“设置”里的标准自动分组。

### 报告生成中心（一键生成全班学习报告）
1. 选班级、单元、日期范围。
2. 下载：
   - `四年级数学_全班学习分析报告.pdf`
   - `四年级数学_全班个人报告汇总.pdf`（所有学生的个人报告合成一个文件，方便一次打印）
   - 全部报告 ZIP（包含全班报告、每位学生的个人报告）
3. 可以只勾选部分学生生成。
4. 在网页中的报告直接填写 **后续行动计划、教师总结、报告确认**，按“保存”后，下载的 PDF 就会包含这些内容。
5. 成绩表可以导出 CSV 或 Excel。

### 题库管理
- 98 道题已依照课本第 23、29 页内容建立并逐题验算（每个知识点 46 道以上）。
- **新增题目**：输入课本算式（例如 `3245 × 19 ÷ 30`），按“自动建立”，系统会算出答案、写出课本格式的解题步骤、提示与常见错误；再选择出现在哪些关卡。
- 选择题：每行一个选项，正确选项前面加 `*`。排序题：按正确顺序每行写一个步骤。
- 保存前系统会重新验算，**答案不对的题目无法保存**。
- 已经有学生作答的题目按“删除”会改为停用，旧报告仍然正确显示。

### 小测与复习活动
- 选题目布置给某一班。**练习**：有提示、可重答；**正式评估**：计分，出现在报告与统计中（在筛选中选择该评估类型）。

### 设置与账户
- 学校名称、教师姓名（印在报告上）。
- 达标线、冲刺及格范围、掌握程度等级名称与分数线、知识点标准、学习困难标准。
- 练习关卡过关标准（首次答对率）、王者认证题数、多次评估时统计哪一次、Boss 计时默认开关。
- 修改密码；管理员可新增其他教师账户。

## 四、评分方式（正式评估）
| 题型 | 满分 | 规则 |
|---|---|---|
| 一步答案题、选择题、排序题 | 1 | 完全正确得 1 分 |
| 两步算式题 | 2 | 第一步 1 分、最后答案 1 分；第一步错但第二步按错的结果算对，得 1 分方法分 |
| 有余数的题 | 2 | 商 1 分；商正确且余数正确再 1 分 |

练习中的提示与重答另外记录，**不影响正式评估分数**。

## 五、教学内容的说明
- 所有解题方法依照老师提供的课本第 23、29 页：从左到右计算、进位写在上方、退位时划去原数字写新数字、两位数乘法写部分积（第二个部分积个位写 0）、长除法写出“16 − 0”这一步、被除数和除数末尾都有 0 时先都除以 10、乘 20 先乘 2 再添 0。
- 课本第 23 页“相差 6 177 张”的思考题，平台的答案（超速与两个表的闯红灯合计）是推断的，已在题目中注明。
- 课本其他页面（例 1、例 2）没有提供，所以没有加入课本以外的方法。
