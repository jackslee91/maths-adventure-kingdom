# 部署说明（Render + Neon PostgreSQL）

本平台是一个 Node.js 网站，**没有任何第三方 npm 套件**，所以不需要 `npm install`。需要的只有：

- Node.js 22.2 或以上（Render 会自动提供）
- 一个 PostgreSQL 数据库（推荐 Neon 免费方案）

> 为什么推荐 Render 而不是 Vercel：本平台是一个一直运行的服务器（保存学生进度、生成 PDF），Render 的 Web Service 可以直接运行；Vercel 适合静态网页和短时间的函数，不适合这种架构。

---

## 一、建立 Neon 数据库（约 5 分钟）

1. 到 <https://neon.tech> 注册并建立 Project，区域建议选 **AWS Asia Pacific (Singapore)**，离马来西亚最近。
2. 在 Dashboard → **Connection Details** 复制连接字符串，看起来像：
   `postgresql://neondb_owner:xxxx@ep-xxxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require`
3. 保存好这串文字，下一步要用。数据库表格会在网站第一次启动时**自动建立**，不需要手动执行 SQL。

## 二、把程序放到 GitHub

1. 在 GitHub 建立一个**私人（Private）**仓库。
2. 把整个 `math-adventure` 文件夹上传（`.env` 文件不要上传，`.gitignore` 已经排除它）。

## 三、在 Render 部署

**方法 A：Blueprint（最简单）**
1. 到 <https://render.com> → New → **Blueprint**，选择你的 GitHub 仓库。Render 会读取 `render.yaml`。
2. 填写环境变量：
   - `DATABASE_URL`：第一步复制的 Neon 连接字符串
   - `ADMIN_USERNAME`：管理员用户名，例如 `admin`
   - `ADMIN_PASSWORD`：管理员密码（至少 8 个字符）
   - `ADMIN_DISPLAY_NAME`：例如 `李老师`
   - `SESSION_SECRET` 会自动产生
3. 按 Apply，等几分钟。完成后打开 `https://你的服务名.onrender.com`。

**方法 B：手动建立 Web Service**
- Runtime：Node　Build Command：`node scripts/verify-questions.js`　Start Command：`node server/index.js`
- Health Check Path：`/api/health`
- 环境变量同上，`SESSION_SECRET` 自己产生：`node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`

第一次启动时，服务器会：
1. 自动建立所有数据库表格（`db/migrations/`）；
2. 载入单元 1.7 的题库（98 道已验证的题目）；
3. 用 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 建立管理员账户。

> Render 免费方案闲置 15 分钟后会休眠，下一位使用者打开时要等大约 30–60 秒。上课前请老师先打开网站“唤醒”它；若要避免休眠，可升级到付费方案。

## 四、第一次使用

1. 用管理员账户登录 → **教师管理中心 → 班级与学生名单** → 新增班级，贴上学生名单（每行“学号 姓名”）。
2. （选做）**设置与账户** → 填写学校名称、教师姓名，调整达标线与掌握程度标准。
3. 把网址发给学生。学生选择班级、输入姓名、设定 4 位数冒险密码就可以开始。
4. 其他老师：管理员在 **设置与账户 → 教师账户** 新增。一般教师只看到自己的班级，管理员可以看全部班级。

## 五、示范数据（可选）

要先看看报告长什么样子，可以在本机或 Render Shell 执行：
```
npm run demo -- 你的用户名
```
会建立“四年级示范班”与 12 位示范学生（经过真实的闯关与评估流程）。示范资料全部标记为“示范”，与真实学生分开。删除：
```
npm run demo -- --remove
```

## 六、在自己的电脑上运行（开发或测试）

```bash
cp .env.example .env        # 填好 DATABASE_URL 和 SESSION_SECRET 等
npm run migrate             # 建立表格
npm run seed                # 载入题库
npm run create-teacher -- teacher1 密码12345 "李老师" admin
npm start                   # 打开 http://localhost:3000
```

## 七、测试

```bash
npm run verify     # 逐题验算整个题库（每道题用独立的 BigInt 计算、竖式引擎与批改引擎核对）
npm test           # 单元测试（数学、批改、竖式、PDF、ZIP）
# API 与安全测试（需要服务器在运行）：
TEST_BASE_URL=http://localhost:3000 TEST_TEACHER=teacher1 TEST_PASSWORD=密码12345 npm test
# 学生端完整流程（需要 Python Playwright）：
python3 tests/e2e/student_flow.py http://localhost:3000 "$DATABASE_URL"
```

## 八、备份与安全

- Neon 有自动备份（Point-in-time restore）。重要考试前也可以在管理中心导出 Excel 成绩。
- 教师密码以 scrypt 加盐哈希保存；学生冒险密码同样加密保存，老师可以重设但看不到原密码。
- 所有教师 API 都在服务器检查登录与班级权限；学生只能读取自己的报告。
- 数据库密码只放在环境变量，不会出现在网页程序中。

## 九、新增单元或题目

- 管理中心 → **题库管理 → 新增单元**，再用 **新增题目** 输入课本算式，系统会自动算答案、写解题步骤、提示和常见错误；**验算不通过的题目无法保存**。
- 大量题目可以修改 `content/generate-questions.js` 后执行 `npm run generate`，再 `npm run seed`。

## 十、技术结构

| 部分 | 说明 |
|---|---|
| `server/` | Node.js HTTP 服务器、API、认证、PDF 生成（`server/pdf/`）、PostgreSQL 客户端（`server/pg/`） |
| `shared/` | 浏览器与服务器共用的数学、竖式、批改引擎 |
| `public/` | 学生游戏、教学模式、管理中心（原生 JavaScript 模块，无需编译） |
| `content/` | 课本分析后的课节与题库生成器 |
| `db/migrations/` | 数据库结构 |
| `server/fonts/` | 嵌入 PDF 的 Noto Sans SC 中文字体（SIL Open Font License） |
