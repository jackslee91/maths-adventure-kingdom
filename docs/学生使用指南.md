# 学生使用指南：数学冒险王

## 一、登记
1. 打开老师给的网址，按 **学生进入游戏**。
2. 选择你的 **班级**，写下你的 **姓名**（和老师名单上的一样）。
3. 第一次进来时，自己设定一个 **4 位数冒险密码**，要记住它！在别的电脑继续冒险时要用到。
4. 忘记密码，请老师帮你重设。班上有同名同学时，要再写学号。

## 二、冒险地图：六座岛屿
| 关卡 | 你要做什么 |
|---|---|
| 1 数学启航站 | 跟着向导阿算看课本例题，一步一步学会竖式，再回答 3 道小问题 |
| 2 解题训练营 | 题目已经做了一半，你来完成：填第二步、竖式填空、排列步骤 |
| 3 独立挑战区 | 自己算计算题和应用题，可以按“获取提示” |
| 4 数学迷宫 | 用答案打开密码门、选对的路、修好断桥、拿到钥匙 |
| 5 终极 Boss 挑战 | 答对题目就能攻击混乱魔王！计时可以自己选择开或关 |
| 6 数学王者认证 | 正式评估：没有提示、不能重答，做完按“提交” |

- 完成一关才能打开下一关。
- 如果某一关答对得不够多，会出现 **补救小站**：再看一次例题、做 3 道简单题，就能继续前进。
- 表现很好时会出现 **宝箱挑战**，答对可以得到“宝箱猎人”徽章。

## 三、答错了怎么办？
- 第一次答错：阿算会告诉你可能错在哪里，改一改再提交。
- 第二次答错：会出现解题步骤和动画讲解，还会先给你一道比较简单的同类题。

## 四、作答小贴士
- 混合运算要 **从左到右** 计算。
- 答案可以写 `10961` 或 `10 961`，也可以加单位，例如 `10 961 张`。
- 有余数的题：在“商”和“余数”两格分别填写。余数一定比除数小！
- 平板或白板上可以用屏幕上的数字键盘（在“设置”里开关）。

## 五、第六关：数学王者认证
- 可以按题号跳到别的题，先做会做的题。
- 中途离开没关系，答案会自动保存。
- 按 **提交认证** 后，看到“✅ 提交成功！老师已收到你的学习记录。”才算交成功。
- 如果网络不好提交失败，你的答案不会不见，按“重新提交”就可以。
- 提交后可以查看、下载或打印你的 **个人学习报告**，请家长在“家长签阅”处签名。

## 六、设置
右上角 **设置** 可以：开关音效与背景音乐、调整音量、开关数字键盘、减少动画效果、登出。


## 选择你的冒险家
第一次登记时，可以选择男生勇者或女生冒险家当主角。想换的话，按右上角“设置”→“更换冒险家”。


## 登记时选名字
选好班级后，如果老师已经输入全班名单，就从“选择你的名字”下拉选单选自己的名字。第一次登记要自己设定 4 位冒险密码，并记住它。名单上找不到名字，选“我的名字不在名单上”，再自己写名字。


## 动作闯关（第 2–5 关）
用 ← → 键（或屏幕上的 ◀ ▶）移动，空格（或“跳”）跳跃，跳上平台可以拿金币。走到怪兽面前，按 **⚔ 出招**（或 J 键）就会出现题目，答对就能打倒怪兽；第四关的门要算出答案才会打开，第五关最后要和混乱魔王决战。不想玩动作关的话，在“设置”勾选“简单模式”，就会直接答题。
